One emoji, one dream vacation, for make.fun's "One Emoji, One Dream Vacation" bounty. The program writes a single emoji to `/output/entry.txt`, where a judge model reads entries two at a time and picks the one that most makes a stranger want to book the flight.

The pick is 🗻 Mount Fuji: one specific, instantly readable postcard — sunrise over Japan's most famous peak — instead of a generic beach or plane.

## Run it

```sh
python3 main.py
```
